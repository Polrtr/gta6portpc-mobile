# Testing

## Run the tests

From the repository root:

```cmd
cmake --build build --config Release --parallel 4
ctest --test-dir build -C Release --output-on-failure
```

The test target uses synthetic byte arrays generated by the test code. No commercial game files are required.

## Current test coverage

- A valid synthetic PE32+ header with the Xbox subsystem marker.
- A valid synthetic Windows CUI PE header.
- Rejection of a missing DOS MZ signature.
- Rejection of an invalid PE signature.
- Rejection of a truncated section-header table.

`horizon-layout-tests` (synthetic PE32 and PE32+ images built in code) additionally covers:

- Optional-header fields, data directories and section table, including section-name sanitising and the security-directory file-offset exception.
- RVA→file-offset translation, including range-crossing, unmapped and wrap-around RVAs.
- Import DLL names, enforcement of the declared import-directory size, rejection of inconsistent RVA/size pairs, unterminated names, non-printable names, out-of-range name RVAs and import tables with no terminator.
- Very large RVA ranges are rejected without integer wraparound; overlapping-section detection avoids quadratic work on untrusted section tables.
- Data-directory counts that do not fit the optional header, undersized optional headers and truncated section tables.
- Warnings for overlapping sections and raw data beyond the supplied bytes.

These tests validate only the metadata parsers. They do not test Xbox package handling, execution, system APIs, graphics, performance or game compatibility.

## Before reporting a result

Include:

- HORIZON commit SHA (`git rev-parse HEAD`).
- OS version and architecture.
- Compiler and version.
- CMake version and generator.
- Exact configure/build/test commands.
- Full relevant output and the failing test name.

## Test-data policy

Use synthetic fixtures or samples you are authorised to inspect. Never commit commercial game executables, game packages, keys, decrypted content, proprietary assets or extracted game data. Do not upload private logs that expose those files or their contents.
